
# wizgen
s a powerful and easy-to-use CLI tool that helps you quickly build MongoDB API projects. With just a few clicks, you can generate a structured project with all the essential components to start your API development.
<a href="https://www.npmjs.com/package/wizgen"><img alt="npm" src="https://img.shields.io/npm/v/wizgen"></a>
### Features
-Automatically generates routes and controllers for basic CRUD operations.
### Usage
```bash
npm i -g wizgen
```
- Run the tool directly from the command line.
```bash
wizgen
```
