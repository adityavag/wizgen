
# wizgen
It is a powerful and easy-to-use CLI tool that helps you quickly build MongoDB API projects. With just a few clicks, you can generate a structured project with all the essential components to start your API development. <br></br>
<a href="https://www.npmjs.com/package/wizgen"><img alt="npm" src="https://img.shields.io/npm/v/wizgen"></a>
### Features
- Automatically generates routes and controllers for basic CRUD operations.
- Quickly create a new MongoDB API project with a well-defined structure.
- User-friendly prompts make it easy for anyone to get started.
### 📦 Installation
```bash
npm i -g wizgen
```
### Usage
After installing, you can run wizgen from the command line:
```bash
wizgen
```
